# Real-Time Edge Detection using OpenCV

This project implements a simple Computer Vision system that performs real-time edge detection using the Canny Edge Detection algorithm.

## Features
- Real-time webcam processing
- Edge detection using OpenCV
- Simple and lightweight implementation

## Technologies Used
- Python
- OpenCV
- NumPy

## Installation

Clone the repository:

git clone https://github.com/SajjadShaik2005/edge-detection-cv-project.git

Navigate to the folder:

cd edge-detection-cv-project

Install dependencies:

pip install -r requirements.txt

## Run the Project

python main.py

Press 'q' to exit the application.

## Applications
- Object detection
- Image preprocessing
- Robotics vision systems
- Autonomous vehicle perception
